1. `display: grid;` 开启网格布局
2. `repeat( auto-fill , minmax(280px, 1fr) )`
   - `minmax(280px, 1fr)`：**单个格子最小宽度 280px，最大可以占满可用空间（1 份）**
   - `auto-fill`：浏览器自动计算，**在容器里尽可能塞多列，每一列不小于 280px**
3. `gap:16px`：行列之间间距都是 16px
4. `localStorage.getItem('foodData')`：从浏览器本地存储读取 key 叫 `foodData` 的字符串
5. `JSON.parse(...)`：把读出来的**JSON 字符串转回 JS 数组对象**（localStorage 只能存字符串，不能直接存数组）
6. `|| [...]` 或运算符：
✅ 如果本地没存过（第一次打开、清空缓存），`getItem` 返回 `null`，`JSON.parse(null)` → `null`，就使用后面这个默认初始数组
7. `JSON.stringify(foodList)`：JS 数组 → JSON 字符串
8. `localStorage.setItem('foodData', 字符串)`：存入本地存储，刷新页面不会丢数据
9. `??` 空值合并运算符,如果 `filterList` 是 `null / undefined`，就用完整的 `foodList`；有传筛选数组就用筛选数组
10. `trim()` 去掉首尾空格；`toLowerCase()` 全部转小写 → **搜索不区分大小写**
11. `filter`：筛选，返回符合条件的新数组
12. `includes`：是否包含子串
13. 对象展开 `...`：保留原来对象所有属性，覆盖新填的这几个字段
14. push 追加进数组末尾
