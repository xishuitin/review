1. <!DOCTYPE html>：以html格式打开
2. <html lang="zh-CN">，用的语言是中文
3. <meta charset="UTF-8">：用UTF-8编码
4. `<meta>`：元标签，**不会显示在页面上**，是给浏览器、搜索引擎看的页面附加信息，放在 `<head>` 标签内。
5. `name="viewport"`：说明这是**视口设置**（viewport = 浏览器可视区域）
6. `initial-scale=1.0`初始缩放比例为 1，页面打开时**不放大、不缩小，1:1 显示** 
7. `*` 叫做**通配符选择器**，选中页面里**所有 HTML 元素**。
8. `margin:0; `  /* 清除所有元素默认外边距 */
9. `padding:0; ` /* 清除所有元素默认内边距 */
10. `box-sizing: border-box`：盒子宽度 = `width`（**padding 和边框会向内挤，不会撑大盒子**）
11. `min-height:100vh; `/* body最小高度占满视口高度，内容少的时候也撑满屏幕 */
12. `background: transparent;` /* body背景透明，才能看到伪元素的背景图 */
13. `position: relative;` /* 给内部绝对定位元素做定位父级 */
14. `font-family`：设置字体
15. `::before` 是**伪元素**，不会写在 HTML 标签里，是自动生成在 body 前面的虚拟元素。
16. content:""; /* 伪元素必须写content，空字符串代表没有文字，只渲染盒子 */
17. position:fixed; /* 固定定位，滚动页面时背景图不动 */
18. inset:0; /* 简写 top:0;right:0;bottom:0;left:0; 盒子铺满整个屏幕 */
19. `background-size:cover` → 盒子里面的图片铺满盒子
20. `url()` 是 CSS 里用来引入**外部资源**的函数
21. `background-repeat: no-repeat;`默认情况下，如果图片**比盒子小**，浏览器会自动横向 + 纵向重复平铺，铺满整个盒子，像瓷砖一样。`no-repeat` = **禁止图片重复平铺，只显示一张**，图片不够大的地方就空出来
22. `filter`: blur(18px)做高斯模糊
23. `z-index `控制堆叠层级，只对设置了 position（relative/absolute/fixed/sticky）的元素生效。
24. `text-align:center`：作用：内部行内 / 行内块元素水平居中，h1、p 默认是块级元素，但文字属于行内内容，所以文字居中。

25. **`display:flex;`**：开启弹性布局。一旦开启，它的**直接子元素**自动变成弹性项目，默认横向排成一行，不再是块元素单独占一整行。
26. **`justify-content:center;`**
控制**主轴（横向）**的对齐方式。主轴水平居中，子元素整体水平居中。
27. `flex-wrap:wrap` 允许子元素**自动换行**：一行放不下，就换到下一行。
28. `border-radius:8px;`圆角，8px，按钮四个角变成圆弧。
29. `cursor:pointer`;鼠标悬浮上去，光标变成**小手**，提示可点击。
30. `transition:0.25s;`：过渡动画0.25s
31. `.nav-item:hover`鼠标移动上去的效果
32. `max-width:1250px`：盒子**最大宽度限制 1250px**；屏幕比 1250px 宽时，容器不会继续拉宽；屏幕小于 1250px，自动跟随屏幕缩小。
